PostgreSQL Submodule Project

Учебный проект демонстрирует подключение внешней библиотеки для работы с PostgreSQL в качестве Git Submodule, а также базовую настройку автоматического тестирования с помощью GitHub Actions.

Назначение

В репозитории реализована функция get_connection_params, формирующая словарь параметров подключения к PostgreSQL. Функция принимает имя базы данных, пользователя и пароль, а также необязательные параметры хоста и порта.

Проект также показывает, как хранить внешнюю зависимость в отдельном Git-репозитории и фиксировать используемую версию зависимости в основном репозитории.

Основные возможности

  • формирование параметров подключения к PostgreSQL;
  • значения хоста и порта по умолчанию: localhost и 5432;
  • подключение внешнего репозитория psycopg/psycopg через Git Submodule;
  • модульное тестирование с помощью pytest;
  • автоматический запуск тестов через GitHub Actions.
