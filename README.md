# PostgreSQL Submodule Project

Практическая работа № 1
Система контроля версий Git

Вариант 5:
Использование submodules для управления
зависимостями проекта.

## Описание

Проект демонстрирует подключение внешней
библиотеки для работы с PostgreSQL
с использованием Git Submodules.

## Структура

- src/ — исходный код проекта;
- lib/postgresql/ — подключенная библиотека PostgreSQL;
- README.md — описание проекта.
