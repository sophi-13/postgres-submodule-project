Работа с Git Submodules

В проект подключён внешний репозиторий https://github.com/psycopg/psycopg.git. Согласно файлу .gitmodules, локальный путь подмодуля — lib/postgresql.

Подмодуль позволяет включить другой Git-репозиторий в состав проекта, сохраняя для него отдельную историю коммитов. Основной репозиторий хранит ссылку на конкретный коммит подмодуля, а не копирует его историю.

Инициализация подмодуля

При первом клонировании используйте:

git clone --recurse-submodules https://github.com/sophi-13/postgres-submodule-project.git

Для уже клонированного проекта:

git submodule update --init --recursive

Проверка состояния

git submodule status

Команда показывает зафиксированный коммит внешней зависимости.

Обновление подмодуля

Чтобы получить более новую версию внешней библиотеки и зафиксировать её в основном репозитории:

cd lib/postgresql
git fetch
git checkout <нужная-ветка-или-коммит>
cd ../..
git add lib/postgresql
git commit -m "Update PostgreSQL submodule"
git push

Обновление подмодуля необходимо фиксировать отдельным коммитом основного проекта. Само по себе получение новых коммитов во внешнем репозитории не меняет версию, на которую ссылается основной репозиторий.
