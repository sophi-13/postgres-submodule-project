
# PostgreSQL Project

## Описание проекта

Проект демонстрирует использование библиотеки Psycopg
для работы с PostgreSQL.

## Основные возможности

- Подготовка параметров подключения к базе данных.
- Работа с библиотекой Psycopg.
- Модульное тестирование.
- Автоматизация тестирования через GitHub Actions.

## Запуск тестов

Для запуска тестов необходимо установить pytest:

    pip install pytest

Запуск тестов:

    python -m pytest -v

## CI/CD

В проекте используется GitHub Actions.

Автоматическое тестирование запускается при отправке
изменений в ветки master, development и release.
