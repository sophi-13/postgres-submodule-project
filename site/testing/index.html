Тестирование и CI

Локальное тестирование

В проекте используется pytest. Тесты расположены в каталоге tests/, а файл pytest.ini задаёт параметр testpaths = tests.

Запуск:

python -m pytest -v

Тесты проверяют: - формирование параметров подключения с настройками по умолчанию; - использование пользовательских значений хоста и порта; - сохранение переданного пароля в возвращаемом словаре.

GitHub Actions

В репозитории настроены workflow для автоматического запуска тестов:

  • main.yml — запускает тесты при отправке коммитов в master и при создании Pull Request в master;
  • development-release.yml — запускает тесты при отправке коммитов в ветки development и release.

Оба сценария используют Ubuntu, Python 3.11, устанавливают pytest и выполняют python -m pytest -v. При получении репозитория workflow также инициализирует подмодули (submodules: recursive).

Результаты выполнения доступны во вкладке Actions репозитория GitHub.
